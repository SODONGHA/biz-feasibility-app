# 사업성 검토 · 원가분석 웹앱 (초안 v0.1)

자동차/부품 신규 사업의 원가분석과 사업성(NPV·IRR·회수기간·손익분기) 판정을 돕는 단일 파일 웹앱입니다.

- 입력한 숫자는 **각자 브라우저에만 저장**되며 서버로 전송되지 않습니다.
- 화면에 들어 있는 숫자는 모두 **예시값**입니다. 실제 견적·실적으로 교체하세요.
- 인쇄/PDF: 상단 "보고서·인쇄" 탭에서 Ctrl+P(⌘P).
- 팀원과 공유: **🔗 공유 링크**(링크 안에 입력 내용 포함, 서버 저장 없음) 또는 **💾 저장 → 파일(.json)** 전달 후 받는 쪽이 **📂 불러오기**.
